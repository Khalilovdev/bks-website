# BKS — Beton Klass Savdo veb-sayti

Bir sahifali korporativ sayt: React + Vite + Tailwind (CDN). UZ/RU ikki tilli.

## Ishga tushirish
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
Natija `dist/` papkasida — istalgan static hostingga (Vercel, Netlify, GitHub Pages) joylanadi.

## Launch oldidan to'ldirish kerak (src/App.jsx boshida)
- `CONTACT` — real telefon, manzil, ish vaqti
- `TG_USERNAME` / `TG_BOT` — Telegram
- `GALLERY` — fotolar
- `SHOW_STATS`, `SHOW_REVIEWS` — real ma'lumotlar kelgach yoqish
- `REQUISITES`, `MAP_EMBED` — rekvizit va xarita
